# 考研政治 · 全真模拟 720 题题库

线上地址：**https://aokid666.github.io/zhengzhi-720/**

把《考研政治全真模拟 720 题》**试题册 + 解析册**做成的可随身刷的网页题库，
并与两份讲义（《考研政治知识清单》《速成班知识点一遍过讲义（大李子）》）做了**逐题对照**。

## 内容

- **785 道题**（单选 386 / 多选 399），5 大模块 · 50 章
- 每题包含：
  1. 题目（题干 + 选项，自动判卷）
  2. **解析**：解析册原页截图（可翻页）+ 可折叠解析文字
  3. **讲义对照**：知识清单 / 速成班讲义的原页截图 + 可折叠文字

## 功能

- **三种笔记**：① 题目与选项上手写批注 ② 解析、讲义的截图与文字上手写批注 ③ 每题独立笔记区（文字 + 手写 + 插图）
- 六色笔 + 荧光笔 + 橡皮，笔画按比例保存，跨设备不错位；顶栏 👁 一键显示/隐藏全部笔记
- 做题记录、错题重做、**蒙对标记**、收藏
- 全文搜索：题干 / 选项 / 解析 / 两份讲义 / 自己的笔记
- **云端同步**：数据存到本仓库 `userdata` 分支的 `userdata.json`，换设备填同一令牌即可看到

## 目录结构

```

data/questions.json 题库（题干、选项、答案、解析、讲义页码）
data/lecture-k.json 知识清单逐页 OCR 文字
data/lecture-s.json 速成班讲义逐页文字

img/k/*.jpg         知识清单 326 页

使用说明.md
```
